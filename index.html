For variable churn, enter one churn rate for each successive churn event. For example: 10, 8, 12, 6. The model calculates the first T payments; it cannot infer infinite lifetime LTV without a future churn assumption.

Payment-by-payment breakdown

Assumptions: fixed price and contribution margin; constant churn only in the first tab; no discounting. CAC applies to each initial user, and one-off implementation cost F is subtracted once. “Exactly n payments” means a user makes payment n then churns before payment n+1. “Per initial subscriber” includes subscribers who might churn before their first payment, not only users who actually paid. In the changing-churn model, a separate churn rate after payment n is needed to calculate exactly n lifetime payments.
